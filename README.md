# Reedición Aerografía Chus

Reedición del blog [Aerografía Chus](https://aerografiachus.blogspot.com/) con un diseño actual y minimalista: 52 proyectos de aerografía sobre cascos, motos, guitarras y otros soportes, de 2009 a 2014.

Web estática, sin dependencias. Los títulos y textos están en `tools/projects.json`, y las páginas se generan con:

```bash
python tools/build.py
```
